BUILD PURPOSE
-------------
v0.0.2-hotfix.2 is a full replacement for the broken hotfix.1 build. It keeps
the entire v0.0.2 feature set and applies both known rendering fixes.

FIXES IN THIS BUILD
-------------------
1. Scene collectible tracker fix:
- cloneScene now uses:
  return { ...s, collected: new Set() };
- This prevents source-scene undefined values from overwriting the newly created
  Set and crashing when game logic calls .has() or .add().

2. Canvas rounded rectangle compatibility fix:
- All direct ctx.roundRect calls were removed.
- Portal rendering now uses a custom roundedRect(context, x, y, width, height,
  radius) path helper based on moveTo and arcTo.
- This avoids browser/WebView compatibility failures in draw code.

3. Persistent runtime diagnostics:
- Any uncaught JavaScript error displays a centered red RUNTIME ERROR panel.
- The browser console also logs the original exception.
- If that panel appears, copy its exact text and report it with a screenshot.

CURRENT FEATURES
----------------
- Standalone HTML5 Canvas game with no external dependencies/assets.
- Symmetric three-deck Transit Hub.
- Exactly two left/right portal destinations per portal deck.
- Central Lift: universal safe deck travel via E menu.
- Secondary stepped platform routes between decks.
- Ascent Deck: two locked ascent portals.
- Central Deck: locked Test Ground left, active Tutorial right.
- Descent Deck: active Stratum 1 left, locked Stratum 2 right.
- Roster Terminal and Hub Storage.
- Recovery beacon.
- Rook: 140 integrity, standard jump, speed 245.
- Nyx: 90 integrity, double jump, speed 315.
- Tutorial: rightward starter route with Salvage, one hazard, extraction.
- Stratum 1: vertical cavern route with Salvage, hazards, extraction, depth HUD.
- Green hazards damage integrity.
- Cyan Salvage pickups are carried during a run.
- Extraction automatically banks carried Salvage.
- Death opens a Run Lost screen and destroys unbanked Salvage.
- Banked Salvage persists in localStorage.

CONTROLS
--------
A / D or Left / Right Arrow: move.
W / Up Arrow / Space: jump.
E: interact.
R: reset current scene.
Esc: close a modal overlay.

CORE LOOP
---------
Hub -> choose fighter -> enter Tutorial or Stratum 1 -> gather Salvage ->
avoid hazards -> extract and bank Salvage OR die and lose unbanked Salvage ->
return to hub.

PERSISTENCE / PERMADEATH
------------------------
Account state is stored through localStorage key: deepgate-account-v002

Persists:
- banked Salvage,
- future account unlocks/progression structure.

Does not persist and is lost on death:
- carried Salvage,
- current health,
- current scene/run position,
- future temporary stats/items/upgrades.

Testing note:
- Browser refresh starts a new run and clears carried Salvage.
- Banked Salvage remains for the same browser profile and site origin.
- Incognito/private mode, clearing site data, or a changed domain/path can
  create a fresh account state.
