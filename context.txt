CONTROLS
--------
A / D or Left / Right Arrow: move.
W / Up Arrow / Space: jump.
E: interact.
R: reset current scene.
Esc: close any overlay.

V0.0.2 PLAY LOOP
----------------
1. Spawn in Transit Hub on the central deck.
2. Use Roster Terminal to choose Rook or Nyx.
3. Use portal routes, lift, or secondary ramps to navigate hub.
4. Enter Tutorial (right portal on central deck) to learn movement, Salvage,
   hazard, extraction, and banking.
5. Enter Stratum 1 (left portal on descent deck) for a longer/deeper risk run.
6. Collect glowing Salvage.
7. Avoid green crystal/energy hazards; hazards damage integrity.
8. Reach an extraction relay and press E to bank all carried Salvage.
9. If integrity reaches zero, current run ends: carried Salvage is lost and
   player returns to the hub after a Run Lost summary.
10. Inspect Hub Storage to see permanent banked Salvage total.

HUB STRUCTURE: IMPLEMENTED
--------------------------
The hub is now a vertically symmetric three-deck transit tower.

Ascent deck:
- West Ascent I: locked left portal.
- East Ascent I: locked right portal.
- Central lift core.

Central deck:
- Test Ground: locked placeholder, left portal.
- Tutorial: active starter portal, right portal.
- Roster Terminal on left side.
- Hub Storage on right side.
- Recovery Beacon and Lift Core at center.

Descent deck:
- Stratum 1: active left portal.
- Stratum 2: locked right portal.
- Central lift core.

Hub rules implemented:
- Every portal deck has exactly two portal destinations.
- Every portal pair is left/right symmetric.
- Central lift provides reliable universal navigation.
- Stepped side ramps provide a manual secondary traversal path between decks.
- Any fighter can reach all hub decks without requiring double jump or special
  movement.

CENTRAL LIFT: IMPLEMENTED
-------------------------
- Interact with any lift core using E.
- Overlay allows immediate safe travel to Ascent, Central, or Descent deck.
- Lift is the authoritative fast/accessible hub route.
- Real-time lift animation is deferred.

SECONDARY TRAVERSAL: IMPLEMENTED
--------------------------------
- Symmetric stepped platform routes on each side of hub join deck elevations.
- They use normal movement/jumping; no special climbing physics required.
- They are optional flavor/expression routes; lift remains primary.

ROSTER: IMPLEMENTED
-------------------
Rook:
- Speed: 245.
- Standard single jump.
- Integrity: 140.
- Gold/orange visual identity.

Nyx:
- Speed: 315.
- Double jump.
- Integrity: 90.
- Purple visual identity.

Selecting a fighter creates a fresh base-kit run, clearing carried Salvage and
restoring integrity to that fighter's maximum.

SCENES: IMPLEMENTED
-------------------
1. Transit Hub
- Three decks, portals/stations/lift and manual ramps.

2. Tutorial: Outbound Walk
- Primarily rightward compact starter route.
- Teaches movement/jump, interaction prompts, Salvage pickup, hazard damage,
  safe extraction, and automatic banking.
- Three Salvage pickups.
- One small hazard.

3. Stratum 1: Gloam Cavern
- Tall vertically descending platform area.
- Fifteen Salvage pickups.
- Multiple increasingly dangerous green crystal/energy hazard fields.
- Extraction relay near bottom route.
- Tracks maximum depth reached for current run.

SURVIVAL / PERMADEATH: IMPLEMENTED
-----------------------------------
Salvage:
- Glowing cyan squares are collectible Salvage.
- Pickups enter RunState.carriedInventory.salvage.
- In zone HUD shows CARRIED SALVAGE.

Hazards:
- Green crystal/energy fields damage player on contact.
- Damage has a short invulnerability interval to prevent instant repeated hits.
- Hazard damage only applies outside the hub.

Extraction:
- Interact with a Safe Extraction/Extraction Relay.
- All carried Salvage transfers automatically to AccountState.hubStorage.salvage.
- Browser account data is saved.
- The run resets to a fresh version of selected fighter at hub.
- A RUN SECURED notification reports banked total.

Death:
- When integrity reaches zero, a Run Lost summary opens.
- Summary displays fighter, maximum depth, Salvage lost, and banked Salvage
  preserved.
- Carried Salvage and all temporary run data are erased on Return to Hub.
- Account banked Salvage remains unchanged.

STATE / PERSISTENCE
-------------------
AccountState, saved with localStorage key "deepgate-account-v002":
- unlockedCharacters
- hubStorage.salvage
- unlockedPortals
- hubUpgrades
- discoveries

RunState, intentionally non-persistent and wiped after death/extraction/new
fighter choice:
- selectedCharacter
- hp
- carriedInventory.salvage
- tempStats
- scene
- maxDepth
- started

Important testing implications:
- Refreshing page creates a fresh run and clears any carried Salvage.
- Banked Salvage remains in same browser/profile/site origin.
- Incognito/private browsing or clearing site data erases localStorage.
- A different GitHub Pages domain/path may have separate browser storage.
