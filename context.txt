BUG REPORT ADDRESSED
--------------------
The v0.0.2-hotfix.2 hub rendered but had three movement/layout defects:
1. Solid central shaft blocks caused player collision/clipping.
2. Those blocks obstructed lift access.
3. The manual stepped path was trapped by full-width deck floor/ceiling colliders,
   so it could not be used to travel between hub decks.

ROOT CAUSE
----------
The hub platform array included central solid rectangles at x=600 to x=900 over
large vertical ranges. These acted as collision blocks rather than decorative
lift shaft walls. Full-width deck slabs at y=440, 830, 1220, and 1560 also
closed off vertical spaces, preventing the side stair steps from functioning as
actual routes between decks.

HOTFIX.3 CHANGES
----------------
1. Removed all central shaft collision blocks.
- The area from x=600 through x=900 is now open transit space.
- The lift cores and beacon remain interactable visual entities, not colliders.
- Player spawn remains on the central deck surface, but is no longer embedded
  inside a solid rectangle.

2. Changed central shaft appearance to rendering-only.
- The shaft is shown as a dashed gold OPEN TRANSIT SHAFT frame.
- It has no physical collision.

3. Preserved lift access.
- Lift cores on central, ascent, and descent deck remain reachable.
- The lift is still the official universal hub travel method.

4. Revised hub physical layout.
- Hub collision geometry now uses deck floors plus side stair steps only.
- Side steps are no longer blocked by central shaft rectangles.
- The layout intentionally keeps the central shaft open and the side routes
  visually/physically separate.

IMPORTANT LIMITATION
--------------------
The existing platform physics treats every platform as a solid rectangle from
all sides. The manual steps now no longer collide with the removed central
shaft, but the design still uses full-width deck floors. This hotfix focuses on
removing the clipping and lift-access defects. If manual travel is still
awkward because a deck floor seals an edge, the next planned revision should
replace side steps with true one-way platforms or explicit ladder/climb zones.
